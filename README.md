VR SketchPad

VR SketchPad is a web application that lets users draw and interact with objects in a virtual 3D environment. I built this project to explore WebXR, Three.js, and React while learning how immersive experiences can be created directly in the browser.

Features

- Draw in a virtual 3D environment
- Interactive hand and controller-based drawing
- Real-time rendering
- Camera and scene controls
- Responsive interface

Tech Stack

- React
- TypeScript
- Three.js
- React Three Fiber
- React Three Drei
- WebXR
- Vite

Getting Started

Clone the repository

```bash
git clone https://github.com/narasimha77-jpg/vr-sketchpad.git
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```

Why I Built This

I wanted to learn how virtual reality experiences are built on the web using modern JavaScript technologies. This project helped me understand 3D rendering, scene management, camera controls, user interactions, and the fundamentals of WebXR while creating an immersive drawing experience.
